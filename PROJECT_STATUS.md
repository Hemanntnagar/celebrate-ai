# Celebrate AI

## Phase 1 — Foundation
Responsive shell, Supabase auth, role-aware event CRUD, preferences, and the complete PostgreSQL schema with RLS.

## Phase 2 — Event Dashboard
Event workspace with persistent last-opened event, overview metrics, preferences, and section navigation.

## Phase 3 — AI Planner
OpenAI structured plans, review-and-apply, revision history, and allocation validation.

## Phase 4 — Budget and Expenses
Categories, allocations, expense ledger, payments, utilization charts, and reconciliation tests.

## Phase 5 — Tasks and Timeline
Task CRUD, assignments, deadlines, dependency cycles, calendar, and change-impact suggestions.

## Phase 6 — Vendors
Directory, quotations, comparisons, booking pipeline, contracts, and payment schedules.

## Phase 7 — Guests and Invitations
Guest lists, CSV import, RSVP links, invitation preview, optional Resend email, and seating.

## Phase 8 — Collaboration and Notifications
Membership roles, activity feed, in-app notifications, and scheduled reminder jobs.

## Phase 9 — Production Hardening
Security notes, migrations, Vitest coverage, accessibility (skip link, focus, scalable viewport), monitoring hook, Vercel cron, and setup docs.
